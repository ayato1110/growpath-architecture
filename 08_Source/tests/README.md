# Tests

Folder ini disiapkan untuk tes end-to-end dan fixture.

Struktur final ada di [`../../03_Application/P13-App-Structure.md`](../../03_Application/P13-App-Structure.md).

Rencana:

```text
tests/
  e2e/
    login.spec.ts
    assessment.spec.ts
    consultation.spec.ts
  fixtures/
```

Tes backend memakai Pytest di `backend/tests/`. Tes frontend memakai Vitest. Tes E2E memakai Playwright.

Tes fitur dikerjakan P14-P15.
