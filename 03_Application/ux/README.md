# UX dan Prototipe P13

Folder ini memuat wireframe low-fidelity dan high-fidelity Growpath P13.

## Isi

| File atau folder | Keterangan |
|---|---|
| `P13-High-Fidelity.figcraft` | Sumber editable high-fidelity |
| `high-fidelity/` | 65 PNG high-fidelity: desktop, mobile, state, overlay |
| `P13-Wireframe.figcraft` | Sumber editable wireframe low-fidelity |
| `wireframe/` | 16 PNG wireframe: desktop, mobile, states, flow |
| `P13-UX-Review.md` | Review antarmuka dan status approve canvas |
| `P13-Wireframe.md` | Struktur wireframe dan daftar layar |
| `P13-Tinjau-Fix.md` | Bukti perbaikan layar Tinjau jawaban |

## Cakupan

- Beranda.
- Data usaha.
- Asesmen lima aspek: Psikografi, Proses Internal, Pasar, Lingkungan, Keuangan.
- Tinjau jawaban 31 nilai.
- Hasil asesmen.
- Rencana aksi.
- Konsultasi.
- Log jawaban.
- Empty, loading, dan error state.
- Desktop 1440 dan mobile 390.

## Cara membuka

1. Buka FigCraft desktop.
2. Buka `P13-High-Fidelity.figcraft` atau `P13-Wireframe.figcraft`.
3. Gunakan PNG di folder masing-masing sebagai pratinjau.

## Batas

- Ini canvas desain, bukan aplikasi yang berjalan.
- Tidak ada klaim backend, skor dinamis, UAT, atau aksesibilitas aplikasi yang sudah diuji.
- Data pada layar adalah data desain, bukan data pengguna nyata.
