# Rencana UAT

## Peserta

- Minimal dua pelaku UMKM untuk menilai lima jawaban AI.
- Jika mitra asli belum tersedia, minimal tiga pengguna proxy dengan profil jelas.

## Skenario

1. Peserta mengisi data usaha.
2. Peserta mengajukan satu pertanyaan konsultasi.
3. Peserta membaca rekomendasi.
4. Peserta melihat log jawaban dan disclaimer.
5. Peserta membuka dashboard.

## Metrik

- Keberhasilan tugas.
- Waktu penyelesaian.
- Kesalahan.
- Skor SUS sepuluh butir.
- Catatan kualitatif.
